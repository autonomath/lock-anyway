Help when you need it

Support

If Lock Anyway isn't behaving as expected, start here.

Install correctly

Drag Lock Anyway into Applications, eject the DMG, and open the copy in Applications. The app won't run from the disk image.

Permission required

If the menu says locking is unavailable, allow Lock Anyway in System Settings → Privacy & Security → Accessibility.

Wrong copy opens

Keep one copy in Applications. Extra copies confuse permissions and Start at Login.

Battery alerts

Turn low-battery alerts on or off in Preferences → Battery, and use the Preview buttons to see each one.

Updating from Idle Lock

Quit Idle Lock and move it to the Trash before installing. macOS may ask for permission again.

Help when you need it

Support

Lock Anyway should disappear into your menu bar. If it does not behave as expected, start with these checks.

Install correctly

Open the DMG, drag Lock Anyway into Applications, eject the DMG, and launch the copy in Applications. The app intentionally will not run from the mounted disk image.

Permission required

If the menu says locking is unavailable, open System Settings → Privacy & Security → Accessibility and allow Lock Anyway. This lets it press the native Lock Screen shortcut.

Wrong copy opens

Keep only one installed copy in Applications. Multiple copies can confuse macOS permission tracking and Start at Login.

Updating from Idle Lock

Quit the old Idle Lock menu-bar app, move Idle Lock.app to the Trash, then install Lock Anyway. macOS may ask you to grant permission again because the application path changed.

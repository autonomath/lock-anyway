Plain-language policy

Privacy

Lock Anyway is a local-only Mac utility. It does not collect, transmit, sell, or share personal data.

Data collection

None. The app has no analytics, advertising, account system, cloud service, tracking SDK, or network feature.

Keyboard and mouse

Lock Anyway reads the macOS idle-time counter: the number of seconds since local keyboard or mouse activity. It does not capture which keys you press, where you click, or what appears on your screen.

Local storage

Your chosen delay, countdown, pause state, and Start at Login preference are stored locally on your Mac. Local diagnostic logs contain app state and errors, not document contents or input events.

Accessibility

On Macs where the legacy lock command is unavailable, Lock Anyway may request Accessibility permission so it can press the native Control–Command–Q Lock Screen shortcut. The permission is not used to inspect other apps.
